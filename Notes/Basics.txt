Namespaces
    General classifiacation, can be used to have multiple  different classes which belong to similar categories.

Classess:

    Class consists of Data and behaviour
    Data = Fields of the class
    Behaviour = Methods of the classes
    Constructor = method with same name of the class, 
                  doesn't have a type,
                  called automatically when the class is triggered
                  if constructor is not defined/declared c# provides a default parameterless constructor
                  When we have more than one constructor whih take different type of parameters, it is called overloading

    Destructor = name same as the class preceeded with ~
                 used to clean up the code

Static and instance classes
    the items which are should be uniform accross all places it is accessed should be marked static to avoid duplication of the same item and make it reusable and save memory
    static items cant be invoked using "this.", they have to be invoked using "ClassName."
    static constructors should not have access modifiers as it cannot be accessed outside the class


Inheritence:
    Useful in reducing redundant code, making common class for shared logic, and accessing it in child classes and adding additional properties in the chilad classes as per requirement
    helps in saving time and reducing errors

Method Hiding:
    If we use the same method name in child class which is used in parent class, the method from parent class is hidden
    for intentional hiding use new keyword
    even after method hiding if we want to use parent class method in child class, use base.item or ((Parent class)child class object).common method name or assign parent class object to child class type
    child class can point to a a parent class reference object but vice versa is not true

Polymorphism
    Polymorphism is to invoke child class variables, through parent class instances at run time
    Override is used to invoke child class objects instead of parent class object
    we need to mark the function in parent class as virtual for making Polymorphism possible
